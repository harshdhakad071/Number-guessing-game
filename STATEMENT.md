# Project Statement

## Project Name

Number Guessing Game

## Problem Statement

Guessing a number can be made into a simple  game. In this project, the computer selects a number between 1 and 100, and the player has to guess the number.

The program tells the user whether the entered number is too high or too low. It also gives hints in the beginning. As the number of attempts increases, the hints become less helpful.

## Objective

The main objective of this project is to create a simple guessing game using basic Python concepts.

The project helps in understanding:

- Variables
- User input
- `if-elif-else` conditions
- `while` loop
- Random number generation
- Counting attempts

## Expected Output

The program should allow the player to keep entering guesses until the correct number is found. It should give suitable messages and hints for incorrect guesses and display the total number of attempts after the correct answer is guessed.

## Tools Used

- Python 3.14
- `random` module

## Scope

This is a basic console-based game. It does not require a database and internet connection.
