# **Number guessing game.**



##### **# Project Description:-**



**The "Number Guessing Game" is a simple Python project where the computer automatically selects a number between 1 and 100, and we have  to guess the number .**



**The game gives hints based on the our guess and then hints become helpful, making the game more fun.**



##### **# Features:-**



**The "Number Guessing Game" is a simple Python project where the computer automatically selects a number between 1 and 100, and we have  to guess the number .**



**The game gives hints based on the our guess and then hints become helpful, making the game more fun.**

##### **# Working process of the game:-**



**1. The computer gives a number between 1 and 100.**

**2. The player enters a guess.**

**3. The program checks the guess:**

- If the guess is too low, it tells the player.
- If the guess is too high, it tells the player.
- If the guess is correct, the game ends.

**4. Hints are provided during the first few attempts.**

**5. After several attempts, the game stops giving additional hints.**

**6. The total number of attempts is displayed when the player wins.**
